\posterheading{1\,~Einstieg}

\subheading{Thema}
Ein Mikrocontroller ist der kleine Rechner in eingebetteten Ger\"aten --
er steuert Sensoren, Tasten und Anzeigen. \textbf{RISC-V} ist eine
offene, lizenzfreie CPU-Architektur und gilt als Zukunftstechnologie.
Das Projekt baut einen RISC-V-Mikrocontroller auf einem \textbf{FPGA}
-- einem programmierbaren Chip, in dem Schaltungen frei beschrieben
werden k\"onnen -- der sp\"ater f\"ur Lehrzwecke eingesetzt werden soll.

\medskip
\noindent
\begin{minipage}[t]{0.48\linewidth}
\subheading{Voraussetzungen}
\begin{itemize}
  \item CPU-Kern: \textbf{LowRISC Ibex} (32-Bit RISC-V), unver\"andert
        \"ubernommen.
  \item Drumherum (RAM, Register, Anzeige, Eingaben\dots) wird selbst in
        SystemVerilog entworfen.
  \item Plattform: \textbf{Digilent Nexys A7-100T} mit Xilinx Artix-7 FPGA.
\end{itemize}
\end{minipage}\hfill
\begin{minipage}[t]{0.48\linewidth}
\subheading{Ziel}
RISC-V und die zugeh\"orige Toolchain als kompletten Lehrbaukasten
verf\"ugbar machen -- und darauf aufbauend ein eigenes, anspruchsvolles
Peripherieger\"at entwerfen.
\end{minipage}

% ----- 2. Zwischenstand -----------------------------------------------
\posterheading{2\,~Zwischenstand}

Der Fokus dieser ersten Phase liegt auf \emph{Toolchain aufbauen und
Grundlagen lernen} -- SystemVerilog, FPGA-Workflow und das
Ibex-Speicher-Interface.

\smallskip
\textbf{Bereits umgesetzt:}
\begin{itemize}
  \item Eigene Bausteine: \textbf{RAM}, \textbf{memory-mapped Register},
        \textbf{Tasten-Entpreller}, \textbf{Z\"ahler},
        \textbf{7-Segment-Anzeige}.
  \item Drei FPGA-Demos auf der Nexys A7: Z\"ahler $\rightarrow$ Anzeige,
        Z\"ahler $\leftrightarrow$ RAM $\rightarrow$ Anzeige, und ein
        erstes Programm auf dem \textbf{Ibex-Core}.
  \item Jeder Baustein hat eine eigene Testbench mit
        \texttt{PASS}/\texttt{FAIL}-Ausgabe.
\end{itemize}

% ----- 3. Quelle ------------------------------------------------------
\posterheading{3\,~Wichtigste Quelle}

\begin{itemize}
  \item Patterson, D.\,A.; Hennessy, J.\,L.: \emph{Computer Organization
        and Design -- RISC-V Edition}, Morgan Kaufmann.
\end{itemize}

\smallskip
Da der Fokus aktuell auf Toolchain und Grundlagen liegt, dient das
